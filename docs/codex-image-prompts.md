# BELLAFOX FEUD — CODEX IMAGE PROMPTS
Twelve assets. Each prompt below is complete and self-contained — the style
block and the avoid-list are already baked into every one. Copy a whole fenced
block and paste it straight into Codex. Nothing to assemble.

## Before you start: one find-and-replace

Five prompts (01, 05, 06, 07, 11) contain this exact line:

> Bella — a confident, friendly young woman game-show host with SHORT_PLACEHOLDER_HAIR and PLACEHOLDER_EYES eyes, wearing a tailored deep-blue show-host blazer with a gold lapel pin, warm genuine smile, poised broadcast posture.

Replace `SHORT_PLACEHOLDER_HAIR` and `PLACEHOLDER_EYES` once, using the wording from
the existing Bella art so she matches the rest of the site — then never change that
sentence again. It is the only thing keeping her the same person across five images.

## Generation order

1. **Asset 05 first.** Generate it, pick the best result, keep that image.
2. Feed that image back into Codex as a reference/attachment for **01, 06, 07, 11**.
3. Everything else (02, 03, 04, 08, 09, 10, 12) has no character in it and can be
   generated in any order.

Skipping step 2 gives you four different hosts.

## Where the files go

`family-feud/img/`, named by base name. **Any of `.webp`, `.png` or `.jpg` works** —
`src/art.js` probes them in that order, so `splash.webp` and `splash.png` are both
found. WebP is preferred: the first five assets came to 808 KB as WebP against a
4 MB budget for the whole folder.

```
splash  backdrop  board-frame  strike-x
bella-idle  bella-win  bella-strike  podiums
round-card  fastmoney-bg  winner  tile
```

Then `node family-feud/tools/check-art.mjs` lists what is present, what is
missing, and anything in `img/` the game will never load — almost always a
filename typo.

## After generating

- Run 03, 04, 05, 06, 07, 08 through background removal if Codex didn't honour transparency.
- Export two sizes of every background: `@1x` (1920w) and `@2x` (3840w), served via `image-set()`.
- Convert to WebP with a PNG fallback. Budget: **under 4 MB for all of `img/`**.
- Check every cutout against the dark stage backdrop, never a white editor canvas — halos
  only show up on the real background.
